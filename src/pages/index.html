// ONE SALES CYCLE, END TO END

From first lead
to a clean payout record.

▲ Capture a lead. Route it to the right agent. Keep the sales trail. Hold and release commission. Resolve disputes with a record you can replay. Tandem gives your app the workflow primitives; you keep the decisions.

// NOTHING EXTRA TO RUN

No servers to manage.
It lives in your app and your database.

Tandem is a library, not a service. There is no separate server, worker, container or queue to deploy.

01 / WHERE IT RUNS

In your Node app

Camp mounts into your Next.js app as one route and runs on Node, like the rest of your app. It does not run on the edge runtime.

02 / WHAT IT NEEDS

A Postgres you already have

On serverless, use a pooled connection. Tandem needs a role it can switch into for row-level security, and init checks that for you.

03 / ONE SCHEDULED CALL

Release held commissions

One database function, release_due_commissions(), releases commissions whose hold has ended. Call it from pg_cron or your host's cron.

// WHAT IT DOES

A CRM foundation
for your app.

Tandem keeps a clear record in Postgres so your app can show the whole sales journey and your team can trace what happened.

01 / EVENT LOG

Append-only source of truth

Every important change is a typed event. You can trace the story without losing earlier decisions.

02 / PROJECTIONS

Rebuildable state

Lead, payout, and activity views build from events. Rebuild them whenever you need to.

03 / MONEY

Integer minor units

Commission amounts use whole cents or sen. Rounding is part of the rule, so the numbers stay clear.

04 / RULES

Qualification & routing

Set a qualification threshold. Choose round robin, least loaded, or manual assignment for each lead.

05 / LIFETIME

Commission on every payment

Each payment earns its own commission line, held until it is ready. Rates can step down as a customer ages, and refunds and clawbacks follow the money. How it works →

06 / AUTH

Vendor-neutral RLS

Use Supabase, plain Postgres, or your own identity provider. Tandem keeps each workspace separate.

// HOW IT WORKS

Start with your app
and Postgres.

Create a lead, record a payment. That is the whole write path. Every step is one function call inside a transaction you control. See the full walkthrough.

signup-and-pay.ts 
import {
  createTandemPool, withTandemSession, createLead, appendLeadEvents, recordPayment,
} from 'tandem-crm/db';
import { defineTandemConfig } from 'tandem-crm';

const pool = createTandemPool(process.env.DATABASE_URL);
const config = defineTandemConfig({
  qualification: { automatedSetupMaxQualificationMetric: 15 },
  commission: {
    holdDays: 30,
    rateSchedule: [
      { fromMonth: 0, basisPoints: 2500 },
      { fromMonth: 12, basisPoints: 2000 },
    ],
  },
});

// 1. A customer signs up, referred by a partner.
const { leadId } = await withTandemSession(pool, adminUserId, (client) =>
  createLead(client, {
    workspaceId, companyName: 'Aman Logistics', contactPhone: '+60 12-345 6789',
    qualificationMetric: 0, productTag: 'starter', partnerId: 'partner-1', config,
  })
);

// 2. They say yes.
await withTandemSession(pool, adminUserId, (client) =>
  appendLeadEvents(client, {
    workspaceId, leadId, events: [{ type: 'conversion.confirmed', data: {} }],
  })
);

// 3. They pay. Every payment earns its own commission line, held for 30 days.
await withTandemSession(pool, adminUserId, (client) =>
  recordPayment(client, {
    workspaceId, leadId, config, source: 'stripe',
    payment: {
      paymentId: 'inv_001', amountMinor: 10000, currency: 'MYR',
      confirmedAt: new Date().toISOString(),
    },
    partnerStatus: async (id) => ({ id, active: true }),
  })
);
// 10,000 sen at 25% is 2,500 sen of commission, held.

// release_due_commissions() runs inside Postgres. Wire it to pg_cron
// or any scheduler you already have. No separate worker process.

// MODULES

The customer journey,
kept together.

A customer's journey from first lead to a clear, lasting record.

Live

Terrain

The ground truth beneath the CRM: leads, typed event history, rebuildable state, exact money math, and tenant-safe Postgres access.

Live

Ascent

Agent onboarding and certification. Teams define the checkpoints; agents complete them; your app decides what certification unlocks.

Live

Camp

A full CRM interface for your team: leads, agents, sales activity, commissions, disputes. It mounts into your own Next.js app in one catch-all route.

Live

Trail

Lightweight sales activity for a real CRM: calls, emails, visits, confidence, stages, corrections, and retractions without deleting history. Log CHAMP qualification when you want it: challenges, authority, money, prioritization.

Live

Waypoint

Territory-aware recommendations for who should own a lead: round-robin, least-loaded, or manual. Terrain records what is true; Waypoint recommends where to go next.

Live

Belay

A safe place to handle commission disputes. It holds a payout while a case is open and records the operator's decision.
